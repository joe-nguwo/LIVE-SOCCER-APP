# LIVE-SOCCER APP 

THIS IS A LIVE-SOCCER-APP IN SVELTE 5

## FEATURES

- LIVE SOCCER UPDATES
- MAJOR SOCCER LEAGUES UPDATES 
- UPCOMMING GAMES
- LATEST SOCCER RESULTS
- TABLE LEAGUES
- MATCH STATS

## TECHNOLOGIES

- SVELTE 5
- TYPESCRIPT
- SHADCN COMPONENTS
- TAILWIND CSS
- LIVE API

### Prerequisites

- Node.js 20+
- Git
- TEXT EDITOR(E.G VSCODE)

### Installation
- CLONE THE REPO i.e GIT CLONE https://github.com/joe-nguwo/LIVE-SOCCER-APP.git
- RUN NPM INSTALL
- CD LIVE-SOCCER-APP
